OWASP VulnerableApp Architecture

VulnerableApp-Facade(Unified UI + Gateway Layer)

A gateway that routes requests to each lab and provides a common UI & API schema across all backends. It contains no vulnerabilities itself.

Java
VulnerableApp(Java / Spring)

The core lab. Intentionally vulnerable Java modules for scanner testing, security research, and training.

JSP
VulnerableApp-JSP(JSP Security Lab)

JSP-based scenarios for evaluating web scanners, payloads, and manual testing techniques.

PHP
VulnerableApp-PHP(PHP Security Lab)

PHP applications covering modern web vulnerability classes.

LLM
LLMForge(AI / LLM Security)

A lab for testing, evaluating, and red-teaming LLM and prompt-based systems.

Key Features

What's included

Multi-stack vulnerability labs

Java, JSP, PHP, and AI/LLM security targets behind one gateway.

Machine-readable ground truth

Every vulnerability exposes its expected findings through a documented endpoint, so scanner results can be scored automatically.

Scanner and payload benchmarking

Evaluate SAST and DAST tools, payloads, and detection rules against known vulnerable scenarios.

Modular vulnerability development

New vulnerability types are self-contained modules; add one without touching the rest of the stack.

Progressive learning path

A step-by-step lab structure with multiple difficulty levels for learners, students, and security newcomers.

Open source

20+ vulnerability categories, and growing

get started

Two ways to run it

Run the full ecosystem with Docker Compose, or a single JAR with no dependency beyond Java.
Both run locally with one command.

Docker Compose — full stack

Best for: benchmarking and realistic scans

Runs the complete stack: the core Java app, extra vulnerable services (JSP, PHP, LLMForge), and the modern React UI.

docker-compose pull && docker-compose up
  • Available at http://localhost
  • This method will run the latest unreleased version. If you want to run the latest released version, please use docker latest tag.

Standalone JAR - minimal setup

Best for: development, debugging and fast setup

Run just the application with the legacy UI.
No Docker needed - Only java.

java -jar VulnerableApp-*.jar
  • Download the JAR from the releases page
  • Run it - the app starts in under a minute
  • Open http://localhost:9090/VulnerableApp
  • Step through vulnerability code in your IDE
USE CASES

Built for Security Testing. Designed for Learning.

Whether you're building scanners, testing defenses, or teaching application security, VulnerableApp provides a controlled environment to explore real vulnerabilities and measure results.

Scanner developers

If you build or contribute to ZAP, Burp extensions, or your own DAST/SAST engine, validate every scan rule against a known, stable target. Write the vulnerability first, then the rule that detects it — test-driven development for security tooling.

Security engineers & AppSec teams

Use VulnerableApp as a fixed reference point for scanners running in CI/CD. Regression-test the pipeline to catch a tool upgrade, config change, or new release that silently stops detecting what it used to.

Educators, students & researchers

A documented, versioned bank of vulnerabilities with escalating difficulty levels — the same lab for every student, the same baseline for every paper.

VulnerableApp

A hands-on platform for learning, experimenting with, and benchmarking application security vulnerabilities.
